# AI System Retirement Checklist

- [ ] Business owner approved retirement
- [ ] Downstream dependencies identified
- [ ] Users notified
- [ ] Model endpoints disabled
- [ ] Credentials / keys revoked
- [ ] Data retention / deletion completed
- [ ] Records and evidence archived
- [ ] Vendor obligations closed
- [ ] Monitoring disabled after confirmation
- [ ] Lessons learned documented
- [ ] AI inventory status changed to Retired
