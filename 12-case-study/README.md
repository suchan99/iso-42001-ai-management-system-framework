# Worked Case Study

The `loan-underwriting-ai` folder is a **fictional worked example** showing how several governance artifacts connect for one AI-assisted decision-support use case.

Use it to understand the reasoning and evidence chain. Do not copy its risk ratings, controls, thresholds, approvals, or monitoring decisions into a real system without performing your own context-specific assessment.

Recommended reading order:

1. `loan-underwriting-ai/system-description.md`
2. `loan-underwriting-ai/impact-assessment.md`
3. `loan-underwriting-ai/risk-assessment.md`
4. `loan-underwriting-ai/controls.md`
5. `loan-underwriting-ai/monitoring-plan.md`
