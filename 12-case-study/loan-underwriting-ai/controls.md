# Loan Underwriting AI — Control Design

## Preventive controls
- Approved feature list
- Training-data provenance review
- Independent model validation
- Fairness testing before deployment
- Explainability acceptance criteria
- Segregated development and production deployment
- Mandatory approval workflow

## Detective controls
- Performance monitoring
- Drift alerts
- Group-level outcome monitoring
- Override-rate monitoring
- Complaint and appeal trend review
- Model/version reconciliation

## Corrective controls
- Disable / rollback capability
- Human-only fallback process
- Incident management
- Root-cause analysis
- Model retraining or recalibration
- Data correction
- Control redesign
