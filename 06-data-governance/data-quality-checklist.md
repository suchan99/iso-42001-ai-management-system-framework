# AI Data Quality Checklist

- [ ] Data source identified
- [ ] Data owner identified
- [ ] Collection purpose documented
- [ ] Provenance recorded
- [ ] Legal / policy basis confirmed where applicable
- [ ] Completeness assessed
- [ ] Accuracy assessed
- [ ] Timeliness assessed
- [ ] Representativeness assessed
- [ ] Label quality assessed
- [ ] Missingness patterns assessed
- [ ] Outliers reviewed
- [ ] Data leakage tested
- [ ] Sensitive attributes identified
- [ ] Proxy-variable risk assessed
- [ ] Training / validation / test separation confirmed
- [ ] Retention requirements documented
- [ ] Access restrictions implemented
